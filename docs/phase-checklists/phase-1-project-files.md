# Phase 1 测试评估验收清单：项目与文件系统

## 自动化测试

- `已关闭` 新建项目会生成 `xtable.project.json` 和推荐目录结构。
- `已关闭` 项目可重新打开，并恢复项目配置。
- `已关闭` 项目配置包含 schema、路径、导出、UI、安全策略和元信息。
- `已关闭` 旧配置打开时可迁移补默认值。
- `已关闭` 保存使用临时文件、fsync 和原子替换。
- `已关闭` 外部修改、只读、写入失败和原子替换失败不会静默覆盖。
- `已关闭` 最近项目记录可去重，记录损坏时可恢复。

## 评估项目

- `已关闭` 项目目录结构满足后续 rules、enums、types、settings、logs、cache、recovery 承载需求。
- `已关闭` 文件错误分类能区分外部修改、只读、权限、占用、磁盘空间、路径缺失和普通写入失败。
- `已关闭` Phase 1 相关 P1/P2 问题已按评估记录关闭。

## 人工验收

- `待验收` 通过 UI 新建项目、关闭后重新打开。
- `待验收` 修改配置后保存，并确认结构完整。
- `待验收` 跨平台检查只读、占用文件和权限异常提示。
