## 自动化测试

- `已关闭` `QAbstractTableModel` 行列数、header、data、setData、flags 测试。
- `进行中` 单元格编辑、提交、取消和只读拒绝测试；`TableWorkbench` 只读写入拒绝反馈和可见编辑提交/取消体验均已复验关闭。
- `进行中` 选择、复制、粘贴、批量填充测试；`TableWorkbench` 单格粘贴、多格粘贴和批量填充撤销/重做闭环均已复验关闭。
- `进行中` 插入、删除、撤销、重做测试；插入删除撤销/重做闭环已复验关闭。

- `已关闭` 表格模型不得绕过 Phase 2 domain 模型直接拼临时结构。
- `进行中` 编辑命令需要形成可撤销/重做边界；单格粘贴、多格粘贴、插入删除、批量填充和键盘复制/粘贴/撤销/重做工作流均已进入 `EditCommandStack` 并复验关闭。

- `已关闭` 必须提供可见 `TableWorkbench`/`TableEditorPage`，否则人工操作测试无法进行。
