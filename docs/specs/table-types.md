# XTable 表格类型规格

## 1. 定位

表格类型系统用于定义一张配置表的结构、编辑视图、导入解析、校验规则和导出行为。MVP 必须支持普通表、分组表和二维表，并预留统一扩展接口。

表格类型逻辑不得散落在 UI、导入导出或校验流程中。新增表格类型必须通过表格类型注册机制接入。

## 2. 通用表格属性

每张表必须包含以下属性：

| 属性 | 必填 | 说明 |
| --- | --- | --- |
| `table_id` | 是 | 项目内唯一表格标识，稳定用于引用和文件存储 |
| `display_name` | 是 | 用户可读名称 |
| `description` | 否 | 表格用途说明 |
| `table_type` | 是 | 表格类型标识 |
| `fields` | 是 | 字段定义列表 |
| `rows` | 是 | 数据行 |
| `primary_key` | 否 | 主键字段，用于跨表引用 |
| `feature_keys` | 否 | 特征键字段列表，用于引用预览 |
| `tags` | 否 | 模块、功能、策划分类等标签 |
| `source_path` | 否 | 来源 Excel/CSV 文件路径 |
| `encoding` | 否 | CSV 或文本源文件编码 |
| `last_modified_at` | 否 | 最近修改时间 |

通用行为：

- 每张表必须声明表格类型。
- 字段顺序必须稳定，避免版本差异中产生无意义变更。
- 主键必须唯一且稳定；特征键只用于展示，不替代主键参与引用存储。
- 表格类型决定专属参数、专属校验、专属导入和专属导出。

## 3. 普通表

### 3.1 基本信息

- 类型标识：`normal_table`
- 显示名称：普通表
- 适用场景：道具、技能、任务、怪物、掉落、成长参数等以“行=记录、列=字段”为核心的配置。

### 3.2 数据结构

```text
NormalTable
  table_id
  display_name
  table_type = normal_table
  fields[]
  rows[]
  primary_key?
  feature_keys[]
```

### 3.3 必需字段

- 至少一个字段。
- 至少一行数据可以为空表创建后再补充。
- 如果该表被其他表引用，必须设置主键字段。

### 3.4 可选参数

- `primary_key`：主键字段。
- `feature_keys`：引用预览字段。
- `default_sort_field`：默认排序字段。
- `readonly_fields`：只读字段集合。

### 3.5 编辑视图要求

- 使用标准二维表格视图。
- 支持单元格、整行、整列和多区域选择。
- 支持插入、删除、复制行列。
- 支持筛选、排序、查找、替换、批量赋值。
- 主键字段和只读字段需要有明确视觉标识。

### 3.6 导入规则

- Excel 工作表或 CSV 文件可导入为普通表。
- 第一行默认识别为字段显示名或字段名。
- 可通过配置识别字段类型行。
- 空行默认跳过；如果空行位于有效数据中间，需要生成 Warn。
- 字段名重复生成 Error。

### 3.7 导出规则

- 按标准行列结构导出为 Excel/CSV。
- 导出字段顺序必须与表结构一致。
- 列表字段、Meta 字段按字段类型导出表达规则输出。
- 导出前必须执行当前表或项目级校验。

### 3.8 校验规则

- 字段类型合法。
- 必填字段非空。
- 唯一字段不重复。
- 主键非空、唯一、类型稳定。
- 引用字段目标存在。
- 枚举字段值在枚举定义内。

### 3.9 日志事件

- 创建普通表。
- 修改表结构。
- 新增、删除、复制行列。
- 修改单元格。
- 设置主键或特征键。
- 导入或导出普通表。

### 3.10 验收标准

- 用户能创建、打开、编辑、保存普通表。
- 普通表可导入导出 Excel/CSV。
- 普通表主键可被其他表引用。
- 校验结果能定位到字段、行和单元格。

## 4. 分组表

### 4.1 基本信息

- 类型标识：`group_table`
- 显示名称：分组表
- 适用场景：同一张表中需要按活动、章节、掉落组、任务组或玩法组维护多组数据。

### 4.2 数据结构

```text
GroupTable
  table_id
  display_name
  table_type = group_table
  fields[]
  rows[]
  group_key
  group_sort?
  group_boundary_style?
```

### 4.3 必需字段

- `group_key` 字段必须存在。
- `group_key` 不能为空。
- 至少一个普通数据字段。

### 4.4 可选参数

- `group_sort`：按 group 顺序、原始顺序或字段排序。
- `group_boundary_style`：导出时的分组边界表达方式。
- `allow_non_contiguous_group`：是否允许同一 group 分散出现，MVP 默认不允许。

### 4.5 编辑视图要求

- 在表格中明确展示 group 边界。
- 支持按 group 折叠和展开。
- 支持按 group 过滤。
- 修改 `group_key` 时需要即时更新 group 归属。
- 无法归组的数据行必须以 Error 标记。

### 4.6 导入规则

- 必须识别 `groupKey` 或配置指定的分组字段。
- 如果缺少 `groupKey`，生成 Error。
- 如果同一 group 不连续，生成 Warn 或 Error，MVP 默认 Error。
- 空 `groupKey` 生成 Error。

### 4.7 导出规则

- 导出时按 group 划分区间。
- 同一 group 的数据应保持连续。
- 导出结果必须包含可识别的 group 边界信息。
- 如果 group 边界生成失败，导出失败并记录 Error。

### 4.8 校验规则

- 缺少 `group_key`。
- `group_key` 字段不存在。
- `group_key` 为空。
- 数据行无法归组。
- 同一 group 非连续。
- group 排序结果不稳定。

### 4.9 日志事件

- 创建分组表。
- 设置或修改 `group_key`。
- group 边界变化。
- group 折叠、展开、批量编辑。
- 分组表导入导出。

### 4.10 验收标准

- 用户能为表设置 `group_key`。
- 编辑区能识别不同 group。
- 缺失、空值、无法归组的数据能被检测。
- 导出结果保留 group 边界。

## 5. 二维表

### 5.1 基本信息

- 类型标识：`matrix_table`
- 显示名称：二维表
- 适用场景：成长曲线、等级参数、坐标矩阵、二维映射、关卡参数矩阵。

### 5.2 数据结构

```text
MatrixTable
  table_id
  display_name
  table_type = matrix_table
  x_axis
  y_axis
  value_field
  cells[]
```

### 5.3 必需字段

- `x_axis`：x 轴字段或轴范围。
- `y_axis`：y 轴字段或轴范围。
- `value_field`：矩阵值字段。

### 5.4 可选参数

- `x_axis_label`：x 轴显示名。
- `y_axis_label`：y 轴显示名。
- `axis_order`：轴排序规则。
- `missing_cell_policy`：缺失坐标处理策略，MVP 默认生成 Error。
- `duplicate_cell_policy`：重复坐标处理策略，MVP 默认生成 Error。

### 5.5 编辑视图要求

- 以矩阵视图展示，x 轴和 y 轴必须清晰可见。
- 支持按坐标定位单元格。
- 缺失坐标、重复坐标和越界坐标需要在视图中标记。
- 允许切换为内部标准行列表视图用于诊断。

### 5.6 导入规则

- 支持从矩阵形 Excel 区域导入。
- 支持从三列结构导入：x、y、value。
- 必须能识别 x 轴、y 轴和值字段。
- 缺失轴定义生成 Error。
- 重复坐标生成 Error。
- 空矩阵生成 Error。

### 5.7 导出规则

- 导出为可阅读矩阵结构。
- x 轴和 y 轴顺序必须稳定。
- 缺失坐标不得静默填充；必须按校验结果处理。
- 导出失败时提供具体坐标和原因。

### 5.8 校验规则

- 缺失 x 轴、y 轴或值字段。
- 坐标重复。
- 坐标缺失。
- 坐标超出轴范围。
- 坐标类型与轴定义不匹配。
- 矩阵为空。

### 5.9 日志事件

- 创建二维表。
- 设置 x 轴、y 轴和值字段。
- 修改矩阵单元格。
- 轴范围变化。
- 二维表导入导出。

### 5.10 验收标准

- 用户能创建二维表并设置 x 轴、y 轴和值字段。
- 用户能编辑 `x * y` 个矩阵值。
- 系统能检测重复、缺失和越界坐标。
- 导出结果能还原为可读矩阵。

## 6. 扩展接入规范

新增表格类型必须提供：

- 类型元数据。
- 专属参数定义。
- 编辑视图能力声明。
- 结构校验规则。
- 内容校验规则。
- 导入解析规则。
- 导出规则。
- 日志事件定义。

新增表格类型不得：

- 在 UI 层直接硬编码导入导出逻辑。
- 绕过统一校验结果结构。
- 绕过统一日志系统。
- 修改已有表格类型行为而不更新本规格文档。

## 7. 与其他模块关系

- 与字段类型：表格类型决定字段组合方式，字段类型决定单元格值规则。
- 与校验系统：表格类型提供结构规则和内容规则。
- 与导入导出：表格类型提供解析和输出策略。
- 与日志系统：表格类型变化、导入导出和结构变更必须记录日志。
