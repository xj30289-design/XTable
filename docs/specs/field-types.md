# XTable 字段类型规格

## 1. 定位

字段类型系统用于定义单元格值的存储形态、编辑器、导入解析、导出表达、排序筛选和校验规则。MVP 固定支持 `string`、`int`、`float`、`bool`、`enum`、`id`、`reference`、`list`、`meta`、`json`。

本规格同时适用于 Table 字段和 Meta 子字段。Meta 子字段与 Table 字段功能相同，复用同一套字段定义、编辑器、导入导出表达、复制粘贴行为、排序筛选能力和校验规则；差异只在字段作用域属于 Meta 类型内部。

## 2. 字段通用属性

| 属性 | 必填 | 说明 |
| --- | --- | --- |
| `field_id` | 是 | 表内唯一字段标识 |
| `name` | 是 | 面向配置和导出的字段名 |
| `display_name` | 是 | 用户可读名称 |
| `description` | 否 | 字段说明 |
| `field_type` | 是 | 字段类型标识 |
| `default_value` | 否 | 默认值 |
| `required` | 是 | 是否必填 |
| `unique` | 否 | 是否唯一 |
| `readonly` | 否 | 是否只读 |
| `range` | 否 | 数值范围或长度范围 |
| `export_name` | 否 | 面向程序的导出字段名 |
| `validation_rules` | 否 | 附加校验规则 |

通用编辑行为：

- 必填字段为空时生成 Error。
- 只读字段不可直接编辑，但可由导入、恢复或系统迁移写入。
- 默认值只在新增行或新增字段时填充，不覆盖已有值。
- 字段显示名可变，字段名应保持稳定。

## 3. 字符串字段

- 类型标识：`string`
- 显示名称：字符串
- 存储值形态：Unicode 文本。
- UI 编辑器：单行文本框，长文本可使用弹出编辑器。
- 默认值规则：默认为空字符串。
- 空值规则：非必填允许为空，必填为空生成 Error。
- 导入解析规则：按文本读取，保留可见空格，移除非法控制字符并生成 Warn。
- 导出表达规则：按文本原样导出。
- 复制粘贴规则：直接复制文本。
- 排序筛选规则：按本地化文本或原始字符串排序。
- 校验规则：长度范围、非法字符、必填、唯一。
- 错误提示示例：`字段 name 不能为空`。
- 验收标准：用户能输入、复制、筛选和导出字符串。

## 4. 整数字段

- 类型标识：`int`
- 显示名称：整数
- 存储值形态：Python `int`。
- UI 编辑器：数字输入框。
- 默认值规则：未配置时默认为空；配置默认值时必须是整数。
- 空值规则：非必填允许为空，必填为空生成 Error。
- 导入解析规则：允许 `1`、`-1`、`0`；小数、科学计数法和非数字文本生成 Error。
- 导出表达规则：导出为十进制整数字符串。
- 复制粘贴规则：粘贴时执行类型解析。
- 排序筛选规则：按数值排序。
- 校验规则：类型、范围、必填、唯一。
- 错误提示示例：`字段 level 需要整数，当前值为 1.5`。
- 验收标准：越界和非整数值能被检测。

## 5. 浮点字段

- 类型标识：`float`
- 显示名称：浮点数
- 存储值形态：Python `float` 或精度安全的十进制表达。
- UI 编辑器：数字输入框。
- 默认值规则：未配置时默认为空。
- 空值规则：非必填允许为空。
- 导入解析规则：允许整数、小数和科学计数法。
- 导出表达规则：使用稳定格式导出，不输出无意义精度抖动。
- 复制粘贴规则：粘贴时执行浮点解析。
- 排序筛选规则：按数值排序。
- 校验规则：类型、范围、精度、必填。
- 错误提示示例：`字段 speed 需要浮点数，当前值无法解析`。
- 验收标准：浮点导入导出前后保持可读和稳定。

## 6. 布尔字段

- 类型标识：`bool`
- 显示名称：布尔值
- 存储值形态：`true` 或 `false`。
- UI 编辑器：复选框或下拉框。
- 默认值规则：未配置时默认为空；可配置为 `true` 或 `false`。
- 空值规则：必填为空生成 Error。
- 导入解析规则：支持 `true/false`、`1/0`、`yes/no`，大小写不敏感。
- 导出表达规则：默认导出 `true` 或 `false`。
- 复制粘贴规则：粘贴时按导入规则解析。
- 排序筛选规则：false 在前，true 在后，空值按筛选条件处理。
- 校验规则：类型、必填。
- 错误提示示例：`字段 enabled 需要布尔值`。
- 验收标准：常见布尔表达能被正确解析。

## 7. 枚举字段

- 类型标识：`enum`
- 显示名称：枚举
- 存储值形态：枚举项 ID 或导出值。
- UI 编辑器：下拉选择器，废弃项带警告标识。
- 默认值规则：可使用枚举类型定义的默认项。
- 空值规则：必填为空生成 Error。
- 导入解析规则：可按枚举项 ID、显示名或导出值匹配，歧义生成 Error。
- 导出表达规则：导出枚举项配置的导出值。
- 复制粘贴规则：粘贴时执行枚举匹配。
- 排序筛选规则：按枚举项排序值或显示名排序。
- 校验规则：枚举类型存在、枚举项存在、废弃项 Warn、必填。
- 错误提示示例：`字段 quality 的枚举值 SSR 不存在`。
- 验收标准：字段能引用全局枚举并识别废弃项。

## 8. ID 字段

- 类型标识：`id`
- 显示名称：ID
- 存储值形态：字符串或整数，按字段配置固定。
- UI 编辑器：文本或数字输入框。
- 默认值规则：可配置自动建议，但 MVP 不要求自动生成。
- 空值规则：主键 ID 必填。
- 导入解析规则：按配置解析为字符串 ID 或整数 ID。
- 导出表达规则：原值稳定导出。
- 复制粘贴规则：允许复制粘贴，粘贴后执行唯一性校验。
- 排序筛选规则：按 ID 类型排序。
- 校验规则：非空、唯一、类型稳定、不可见非法字符。
- 错误提示示例：`主键 id 重复：1001`。
- 验收标准：重复 ID 和空 ID 可被检测。

## 9. 引用字段

- 类型标识：`reference`
- 显示名称：引用
- 存储值形态：目标表主键值。
- UI 编辑器：引用选择器，展示目标表特征键预览。
- 默认值规则：默认为空。
- 空值规则：必填为空生成 Error，非必填为空允许但可显示提示。
- 导入解析规则：按目标表主键解析。
- 导出表达规则：导出目标表主键值。
- 复制粘贴规则：粘贴后检查目标是否存在。
- 排序筛选规则：按引用值或特征键预览排序。
- 校验规则：目标表存在、目标字段存在、目标主键存在、循环依赖检测。
- 错误提示示例：`字段 item_ref 引用的目标 ID 2001 不存在`。
- 验收标准：引用可跳转到目标表或显示缺失目标说明。

## 10. 列表字段

- 类型标识：`list`
- 显示名称：列表
- 存储值形态：有序数组。
- UI 编辑器：列表编辑器，支持元素新增、删除、排序、复制、粘贴。
- 默认值规则：默认为空列表或配置默认元素。
- 空值规则：非必填允许空列表，必填要求至少一个有效元素。
- 元素类型限制：元素可为基础类型、枚举、引用、Meta 或 Json；MVP 允许嵌套列表但最大深度默认 3。
- 空元素处理：空元素默认生成 Warn；必填元素为空生成 Error。
- 元素唯一性：可配置是否要求列表内唯一。
- 导入解析规则：使用稳定文本表达解析，例如 `[1001,1002]` 或配置的分隔表达。
- 导出表达规则：导出为稳定、可解析、保留顺序的文本表达。
- 复制粘贴规则：支持整列表达复制和单元素复制。
- 排序筛选规则：默认按文本表达筛选，不参与普通数值排序。
- 校验规则：元素类型、元素数量范围、空元素、唯一性、嵌套深度。
- 错误提示示例：`字段 rewards 的第 3 个元素不是合法引用`。
- 验收标准：列表字段可编辑、导入、导出、校验并保持元素顺序。

## 11. Meta 字段

- 类型标识：`meta`
- 显示名称：自定义数据元
- 存储值形态：结构化对象。
- UI 编辑器：嵌套表单或弹出编辑器。
- 默认值规则：按 Meta 子字段默认值生成。
- 空值规则：非必填允许整体为空；必填时要求必填子字段有效。
- 导入解析规则：从稳定文本表达或结构化列解析。
- 导出表达规则：导出为稳定、可解析、保留子字段名和值的复合表达。
- 复制粘贴规则：支持整体复制，粘贴时检查 Meta 类型匹配。
- 排序筛选规则：默认按导出表达筛选，不参与普通排序。
- 校验规则：Meta 类型存在、子字段存在、子字段类型合法、嵌套深度、复杂度阈值。
- 错误提示示例：`字段 condition 的子字段 op 不能为空`。
- 验收标准：Meta 字段能复用自定义数据元并参与校验和导出。

## 12. Json 字段

- 类型标识：`json`
- 显示名称：Json
- 存储值形态：JSON 对象、数组、字符串、数字、布尔值或 `null`，内部应保留为解析后的 JSON 值，并保存稳定格式化文本用于显示和导出。
- UI 编辑器：Json 专用编辑器，支持多行编辑、语法高亮、缩进格式化、折叠展开、错误位置提示和一键格式化。
- 默认值规则：未配置时默认为空；可配置为 `{}`、`[]` 或任意合法 JSON 值。
- 空值规则：非必填允许为空；必填为空生成 Error；必填但值为 JSON `null` 时按字段配置决定是否允许，默认不允许。
- 导入解析规则：从 Excel/CSV 文本中解析 JSON；允许合法 JSON 对象、数组和基础 JSON 值；解析失败生成 Error，并记录错误行列和字符位置。
- 导出表达规则：导出为稳定、可解析 JSON 文本；默认使用紧凑格式，用户可在导出选项中选择格式化输出。
- 复制粘贴规则：复制时输出 JSON 文本；粘贴时立即解析并提示语法错误；粘贴多行 JSON 时不得拆分为多个单元格。
- 排序筛选规则：默认按格式化后的文本筛选；不参与数值排序；可按 JSONPath 或键名搜索作为后续扩展。
- 校验规则：JSON 语法、最大文本长度、最大嵌套深度、必需键、禁止键、值类型、数组元素类型、Schema 约束。
- 错误提示示例：`字段 extra_config 不是合法 Json：第 1 行第 12 列缺少逗号`。
- 验收标准：Json 字段可编辑、格式化、导入、导出、复制粘贴，并能显示语法和内容校验错误。

### 12.1 Json 内容校验

Json 字段除语法校验外，还支持内容校验。内容校验用于约束 Json 内部结构，避免把不可读或不可消费的自由文本塞进配置表。

MVP 支持的 Json 内容校验：

- 是否必须为对象。
- 是否必须为数组。
- 必需键列表。
- 禁止键列表。
- 键的值类型，例如 string、number、integer、boolean、object、array、null。
- 数组元素类型。
- 最大嵌套深度。
- 最大字符长度。
- 最大数组长度。
- 最大对象键数量。

Json 内容校验结果必须定位到：

- 字段。
- 行。
- 单元格。
- Json 路径，例如 `$.rewards[0].item_id`。
- 错误原因。
- 建议修复方式。

### 12.2 Json UI 能力

Json 字段相关 UI 必须支持：

- 单元格内显示 Json 摘要，例如 `{...}`、`[...]` 或首层键预览。
- 双击或快捷键打开 Json 编辑器。
- Json 编辑器内支持语法高亮、格式化、压缩、错误定位。
- 校验错误需要在 Json 编辑器中定位到具体行列或 Json 路径。
- 字段属性面板支持配置 Json 内容校验规则。
- 问题报告点击 Json 校验问题时，跳转到源单元格并打开 Json 编辑器定位问题。

## 13. 字段类型扩展规范

新增字段类型必须定义：

- 类型标识和显示名称。
- 存储值形态。
- UI 编辑器。
- 默认值、空值、导入和导出规则。
- 复制粘贴、排序筛选、校验规则。
- 错误提示示例和验收标准。

新增字段类型不得绕过统一校验结果、日志系统和导入导出接口。
