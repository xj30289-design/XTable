# XTable 全局枚举规格

## 1. 定位

全局枚举用于在项目范围内维护可复用的枚举定义，避免不同配置表重复维护同一组选项。枚举字段只能引用全局枚举类型，不允许在单个字段内私有维护一套与项目不一致的枚举项。

## 2. 枚举类型结构

枚举类型至少包含：

| 属性 | 必填 | 说明 |
| --- | --- | --- |
| `enum_id` | 是 | 项目内唯一枚举类型 ID |
| `display_name` | 是 | 用户可读名称 |
| `description` | 否 | 枚举用途说明 |
| `items` | 是 | 枚举项列表 |
| `default_item_id` | 否 | 默认枚举项 |
| `allow_deprecated_display` | 是 | 是否允许废弃项继续显示 |
| `export_name` | 否 | 面向程序的导出名称 |
| `created_at` | 否 | 创建时间 |
| `updated_at` | 否 | 最近更新时间 |

枚举类型规则：

- `enum_id` 必须稳定，不应随显示名变化而变化。
- 同一项目内 `enum_id` 不得重复。
- 删除枚举类型前必须检查引用影响。
- 如果枚举类型已被字段引用，默认不允许直接删除，只允许废弃或迁移。

## 3. 枚举项结构

枚举项至少包含：

| 属性 | 必填 | 说明 |
| --- | --- | --- |
| `item_id` | 是 | 枚举类型内唯一枚举项 ID |
| `display_name` | 是 | 用户可读名称 |
| `export_value` | 是 | 面向程序或表格导出的值 |
| `description` | 否 | 枚举项说明 |
| `sort_order` | 是 | 显示和导出排序 |
| `deprecated` | 是 | 是否废弃 |
| `deprecated_reason` | 否 | 废弃原因 |
| `updated_by` | 否 | 最近修改人 |
| `updated_at` | 否 | 最近修改时间 |

枚举项规则：

- 同一枚举类型内 `item_id` 不得重复。
- 同一枚举类型内 `export_value` 默认不得重复。
- 废弃项不应出现在新建数据的默认候选列表中。
- 既有数据引用废弃项时生成 Warn，不自动替换。

## 4. 枚举项废弃机制

废弃用于保留历史数据可读性，同时阻止新数据继续使用旧选项。

行为要求：

- 废弃项在枚举管理界面中可见，并带明确废弃标识。
- 枚举字段下拉选择器默认隐藏废弃项，但已有单元格值为废弃项时必须显示。
- 使用废弃项的数据生成 Warn。
- 如果废弃项被设为默认值，生成 Error。
- 废弃项恢复启用时必须记录日志。

## 5. 枚举引用影响分析

枚举类型或枚举项变更前，需要提供引用影响查看：

- 哪些表引用该枚举类型。
- 哪些字段引用该枚举类型。
- 哪些单元格使用被修改或废弃的枚举项。
- 修改 `export_value` 会影响哪些导出结果。
- 删除或废弃枚举项是否会产生 Error 或 Warn。

引用影响结果应能跳转到对应表、字段、行和单元格。

## 6. 枚举导入导出

导入：

- 支持从项目枚举定义文件导入。
- 支持从已有配置表字段推断候选枚举，但 MVP 不要求自动生成。
- 导入时检测重复 `enum_id`、重复 `item_id`、重复 `export_value`。

导出：

- 面向程序的导出接口必须包含枚举类型 ID、导出名称、枚举项 ID、导出值、废弃状态。
- Excel/CSV 数据导出时，枚举字段导出枚举项的 `export_value`。
- 废弃项导出不失败，但需要在校验报告中保留 Warn。

## 7. UI 功能

Enum 功能窗口必须支持：

- 枚举类型列表。
- 枚举类型创建、重命名、编辑描述。
- 枚举项新增、编辑、排序、废弃、恢复。
- 默认枚举项设置。
- 引用影响查看。
- 枚举搜索和筛选。

## 8. 校验规则

枚举相关校验包括：

- 枚举类型不存在：Error。
- 枚举项不存在：Error。
- 枚举项已废弃：Warn。
- 枚举项导出值重复：Error。
- 默认枚举项不存在或已废弃：Error。
- 字段引用枚举类型但字段值为空：按字段必填规则处理。

## 9. 日志事件

必须记录：

- 创建、修改、删除或废弃枚举类型。
- 新增、修改、排序、废弃或恢复枚举项。
- 修改枚举项导出值。
- 查看引用影响。
- 导入或导出枚举定义。

## 10. 验收标准

- 用户能创建、编辑、删除或废弃枚举项。
- 字段能引用全局枚举。
- 废弃枚举项在已有数据中可被识别并提示。
- 程序侧能导出枚举定义。
- 修改枚举前能查看引用影响。
