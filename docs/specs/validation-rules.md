# XTable 校验规则规格

## 1. 定位

校验系统用于在导入、编辑、保存和导出过程中发现配置问题，并以统一结构提供给 UI、导出阻塞、日志和诊断系统。

## 2. 统一校验结果结构

每条校验结果必须包含：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `issue_id` | 是 | 问题唯一 ID |
| `severity` | 是 | 严重级别：Error、Warn、Info |
| `issue_type` | 是 | 问题类型 |
| `table_id` | 否 | 所属表 |
| `table_type` | 否 | 表格类型 |
| `field_id` | 否 | 字段 |
| `field_type` | 否 | 字段类型 |
| `row_index` | 否 | 行号 |
| `column_index` | 否 | 列号 |
| `cell_coord` | 否 | 单元格坐标 |
| `reason` | 是 | 问题原因 |
| `suggestion` | 是 | 修复建议 |
| `blocks_export` | 是 | 是否阻塞导出 |
| `created_at` | 是 | 生成时间 |

## 3. 严重级别

- `Error`：阻塞保存或导出的严重问题，必须修复。
- `Warn`：不阻塞导出，但需要用户确认或关注。
- `Info`：提示信息，不阻塞流程。

阻塞导出规则：

- 存在任意 `Error` 时禁止导出。
- 仅存在 `Warn` 时，用户确认后可以继续导出。
- `Info` 不影响导出。

## 4. 校验时机

- 导入后自动校验。
- 单元格编辑后局部校验。
- 保存前校验当前项目。
- 导出前强制校验。
- 修改 Enum、Meta、字段结构后校验影响范围。

## 5. 字段类型校验

通用字段校验：

- 必填为空：Error。
- 字段类型不匹配：Error。
- 唯一字段重复：Error。
- 只读字段被用户直接修改：Warn 或 Error，按操作来源判断。
- 默认值类型不匹配：Error。

类型专属校验：

- `string`：长度越界、非法不可见字符。
- `int`：非整数、数值越界。
- `float`：非数字、数值越界、精度不稳定。
- `bool`：无法解析为布尔值。
- `enum`：枚举类型不存在、枚举项不存在、枚举项已废弃。
- `id`：空 ID、重复 ID、主键类型不稳定。
- `reference`：目标表不存在、目标字段不存在、目标主键不存在。
- `list`：元素类型错误、空元素、长度越界、元素重复、嵌套深度越界。
- `meta`：Meta 类型不存在、子字段缺失、子字段类型错误、必填子字段为空。
- `json`：JSON 语法错误、内容校验失败、必需键缺失、禁止键存在、值类型不匹配、数组元素类型不匹配、嵌套深度越界、字符长度越界。

## 6. 表格类型校验

普通表：

- 字段名重复。
- 主键缺失。
- 主键重复。
- 特征键字段不存在。

分组表：

- 缺少 `group_key`。
- `group_key` 字段不存在。
- `group_key` 为空。
- 数据行无法归组。
- 同一 group 非连续。

二维表：

- 缺少 x 轴、y 轴或值字段。
- 坐标重复。
- 坐标缺失。
- 坐标越界。
- 坐标类型不匹配。
- 矩阵为空。

## 7. Enum 校验

- 枚举类型不存在：Error。
- 枚举项不存在：Error。
- 枚举项已废弃：Warn。
- 枚举项导出值重复：Error。
- 默认枚举项不存在：Error。
- 默认枚举项已废弃：Error。
- 删除枚举类型前存在引用：Error。

## 8. Meta 校验

- Meta 类型不存在：Error。
- 子字段不存在：Error。
- 子字段类型不合法：Error。
- 必填子字段为空：Error。
- 嵌套深度超过限制：Error。
- 复杂度超过建议阈值：Warn。
- Meta 导出表达无法稳定生成：Error。

## 9. 跨表引用校验

- 引用目标表不存在：Error。
- 引用目标字段不存在：Error。
- 引用目标主键不存在：Error。
- 引用目标重复导致歧义：Error。
- 循环依赖：Error。
- 关键配置表缺失：Error。
- 引用字段为空：按字段必填规则处理。

## 10. 导入导出校验

导入异常：

- 文件不存在或不可读：Error。
- 编码错误：Error。
- CSV 分隔符异常：Error。
- 表头缺失：Error。
- 字段名重复：Error。
- 空文件：Error。
- 部分行解析失败：Warn 或 Error，按失败范围判断。

导出异常：

- 目标路径不存在：Error。
- 目标文件不可写或被占用：Error。
- 导出结果为空：Error。
- 导出前存在阻塞错误：Error。
- 分组表 group 边界生成失败：Error。
- 二维表矩阵还原失败：Error。
- 列表、Meta 或 Json 字段表达式生成失败：Error。

Json 导入导出异常：

- Json 文本解析失败：Error。
- Json 内容校验失败：Error。
- Json 导出文本无法重新解析：Error。
- Json 格式化或压缩失败：Error。
- Json 路径定位失败：Warn。

## 11. 问题定位

问题报告视图必须支持：

- 按严重级别筛选。
- 按表筛选。
- 按表格类型筛选。
- 按字段筛选。
- 按字段类型筛选。
- 按规则类型筛选。
- 按关键词搜索。
- 点击问题跳转到源单元格。
- 展示问题原因和建议修复方式。
- 复制或导出异常摘要。
- Json 校验问题需要展示 Json 路径，并能打开 Json 编辑器定位到对应行列或路径。

定位规则：

- 单元格问题必须包含表、行、字段或单元格坐标。
- 表结构问题必须包含表和相关字段。
- 跨表引用问题必须包含源位置和目标说明。
- 导入导出问题必须包含文件路径或目标路径。

## 12. 日志关系

校验系统必须记录：

- 手动校验开始和结束。
- 导入后自动校验。
- 导出前强制校验。
- Error/Warn/Info 数量。
- 阻塞导出的原因摘要。
- 高风险问题自动展开问题抽屉的事件。

## 13. 验收标准

- 所有校验结果使用统一结构。
- Error 能阻塞导出。
- Warn 能在用户确认后允许导出。
- 问题报告能定位到表、字段、行、单元格。
- 校验结果能被日志和诊断系统复用。
