# Phase 1.5 UI Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independent, reusable XTable UI Kit and Demo shell before real editor business features begin.

**Architecture:** Add a `xtable.ui.components` package for reusable widgets, a `xtable.ui.shell` module for editor shell composition, and a `xtable.ui.demo` entrypoint for static UI Kit preview. The existing main window keeps project behavior but gains a menu entry that opens the UI Demo.

**Tech Stack:** Python 3.12, PySide6/Qt Widgets, pytest with `QT_QPA_PLATFORM=offscreen`, existing SVG icon loader and QSS theme builder.

```python
from __future__ import annotations

from PySide6.QtCore import QSize
from PySide6.QtWidgets import QToolButton

from xtable.ui.icons import icon_for


class IconToolButton(QToolButton):
    def __init__(self, icon_id: str, tooltip: str, *, theme: str = "light", size: int = 20) -> None:
        super().__init__()
        self.icon_id = icon_id
        self.setObjectName(f"icon-tool-button-{icon_id}")
        self.setProperty("icon-id", icon_id)
        self.setProperty("theme", theme)
        self.setToolTip(tooltip)
        self.setAccessibleName(tooltip)
        self.setText("")
        self.setIconSize(QSize(size, size))
        self.apply_theme(theme)

    def apply_theme(self, theme: str) -> None:
        self.setProperty("theme", theme)
        self.setIcon(icon_for(self.icon_id, theme))
```
